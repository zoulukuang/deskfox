## 签名的真实账单

如果你还是想走直接 exe 分发路径，签名成本这样算：

| 方案 | 成本 | 效果 |
|---|---|---|
| **SignPath.io** | **免费**（开源项目） | 主流方案，很多开源项目在用 |
| **Azure Trusted Signing** | $9.99/月 | 微软新服务，门槛低 |
| 普通 OV 证书 | ~$100-300/年 | 需累积下载量才消警告 |
| **EV 证书** | ~$300-500/年 | 立即获得 SmartScreen 信誉 |

开源项目几乎都走 SignPath.io 免费路径。

## 给你的最优路径

**阶段推进，全程无需花钱买签名**：

1. **自用阶段**：Bun 编译单 exe，GitHub Release 挂着 → 自己和同事手动下载
2. **小范围推广**：开 Scoop bucket → `scoop install` 体验立即拉满，**完全避开签名问题**
3. **扩大用户**：提交 winget manifest → 覆盖非技术用户
4. **正式发布**：申请 SignPath.io 免费签名，三平台 CI 集成

**结论**：CLI 形态 + Scoop 分发 = 技术用户体验最好、完全规避签名警告、0 成本。这比纠结"本地打包 vs GitHub 打包"或"要不要 installer"更关键。
