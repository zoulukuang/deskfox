# macOS 2026.12.0 发布准备

2026-10-20 用户要求同步最新代码、处理 Mac 剩余事项并准备发布。基线 origin/main 65b23fca0b；Windows 已发布 2026.12.0，Mac 当前 2026.11.2。本轮生成 Mac 同功能波次候选，保留主目录两处用户改动，不将未发布候选写入正式 ship 台账。

验收清单：
- [x] Mac wrapper 支持保持应用运行且隔离输出；拒绝默认目录及别名，不覆盖正在使用的应用。
- [x] 真实 MacUpdater 验证低版本/同版本不可更新、高版本可更新，自动下载/退出安装保持关闭；双架构资源分流正确。
- [x] 冻结依赖安装、全量 pre-push、分享专项与服务端测试、端到端及生产性能测试；失败保留证据。
- [ ] 39 条数据库迁移基线一致；旧数据只读备份核对；候选两次冷启动无新增隔离。
- [ ] macOS 原生附件入口与取消/草稿保留检查；已验证项与无法执行项分开记录。
- [ ] arm64/x64 同号候选包，插件、LO、原生模块架构、品牌/版本、签名和公证逐项校验。
- [ ] 发布说明、制品 hash 与后续发布命令可复核；不提前改线上更新源、正式安装或公开 Release。
