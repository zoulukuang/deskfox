# macOS 2026.12.0 发布准备

2026-10-20 用户要求同步最新代码、处理 Mac 剩余事项并准备发布。基线 origin/main 65b23fca0b；Windows 已发布 2026.12.0，Mac 当前 2026.11.2。本轮生成 Mac 同功能波次候选，保留主目录两处用户改动，不将未发布候选写入正式 ship 台账。

验收清单：
- [x] Mac wrapper 支持保持应用运行且隔离输出；拒绝默认目录及别名，不覆盖正在使用的应用。
- [x] 真实 MacUpdater 验证低版本/同版本不可更新、高版本可更新，自动下载/退出安装保持关闭；双架构资源分流正确。
- [x] 冻结依赖安装、全量 pre-push、分享专项与服务端测试、端到端及生产性能测试；失败保留证据。
- [x] 39 条数据库迁移基线一致；旧数据只读备份核对；候选两次冷启动无新增隔离（私有旧库与安装副本，不替换正在使用的正式版）。
- [x] macOS 原生附件入口与取消/草稿保留检查；Finder 合成 CSV、PNG、PDF 真实混合拖放及取消/确认发送通过。
- [x] arm64/x64 同号候选包，插件、LO、原生模块架构、品牌/版本、签名和公证逐项校验。
- [x] 发布说明、四个制品 SHA-256、更新清单 SHA-512/大小与发布 dry-run 可复核；未改线上更新源、正式安装或公开 Release。
- [ ] Intel 正常启动与健康性能验收。2026-10-21 用户确认无可用 Intel 环境，先保留发布阻断；不得以 Rosetta 下发送成功代替性能验收。
- [ ] 排查用户新报“找不到用于储存 DeskFox Key 的钥匙串”系统弹窗。当前 Electron 42.3.3 早于相关惰性初始化修复 42.4.1；需确认触发实例及测试 HOME 隔离的影响，不重置用户钥匙串。

版本采用官方 bump 脚本将 macos 从 2026.11.2 升至 2026.12.0，其他平台/渠道不动。签名公证使用既有官方凭据；正式分发须双架构均通过。原生正式版当前运行，构建不终止其进程。
