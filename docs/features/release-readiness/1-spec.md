# 2026.12.0 发版准备

用户于 2026-10-19 授权处理发版检查的六项缺口：分享回归、Windows 补丁集成、原生矩阵、正式安装升级、分享站运营保障、最终验收与台账。

随后用户明确本机只负责 Windows 发布；Mac 内测由同事处理。Mac／手机实机不作为本次 Windows 发布准备的本机交付门，保留交接记录。

运营口径已明确确认：公开分享保留到用户取消；取消删除在线正文；同区域备份最多保留七天。恢复必须叠加最新删除记录。公开分享不新增自动过期。

验收：

- 分享请求与模型目录刷新分别验证，精确断言一次创建和初始同步的地址与方法；完整分享回归通过。
- SolidStart 补丁在锁定安装中生效，真实配置／路由发现及生产构建通过。
- 29 包类型检查、六包测试、默认端到端、生产性能套件全部有本轮结果；失败保留日志并分诊。
- 七天备份边界、近期备份保留、跨区／损坏／软链接拒绝验证；备份失败不能清理历史备份，必须恢复服务。
- 生成隔离输出的 Windows 正式候选包并核对品牌、版本、插件和 LibreOffice；安装升级必须在隔离系统验收。
- 原生 Windows、macOS、手机、WSL／SSH 按实际环境记录。没有设备或未运行的项目不得标通过。

本批准备发布，不自动创建公开 Release、更新线上客户端清单或覆盖正式安装。提交前对受保护文件提供逐项 R4 复核；安装升级及跨平台环境缺口保持显式。

2026-10-20 用户追加授权：在当前 Windows 电脑正常退出正式版，备份旧安装及三个数据目录后执行 2026.12.0 候选升级；本轮安装验收采用当前电脑，不再等待隔离系统。公开发布与线上更新清单仍待单独发布指令。

2026-10-20 用户报告再次启动后会话消失，撤回“准备完成”。新增复现及验收：使用真实 electron-updater 验证较旧线上版本不得成为更新、同版不更新、新版仍可更新；恢复被隔离原库前保留当前库与原件，验证候选基线与原库匹配；修正候选重新安装后，更新检查及两次冷启动均不隔离旧库，原有会话仍可列出。不关闭真正超前数据库的隔离保护。
