Public sharing notice

2026-10-19

A session is uploaded to the sharing service only when you choose to publish it. Anyone with the link can read it. Review messages, tool output and attachments before publishing.

The first publish action selects deskfox.cn (mainland China) for the Simplified Chinese desktop language, and deskfox.ai (overseas) for other languages. An existing share stays with its original service; changing language does not move or copy it.

While published, a session snapshot is stored and subsequent session content is synchronized. Public data can include messages, attachments and tool results. Model connection settings, request headers and API URLs are filtered; secrets included in message text or tool output are not all automatically detected.

Unpublish in the desktop app makes the public page and data unavailable and removes the live content. A deletion record without the content remains to prevent retries or old backups from making it public again. Unpublishing cannot remove copies saved by other people.

Public shares remain available until you unpublish them. The overseas sharing service creates daily private backups in the same region and removes backups at the seven-day retention cutoff during scheduled maintenance. Restoring a backup applies the latest deletion records so cancelled shares cannot become public again. Website servers process IP addresses and request logs for operation and abuse prevention, separately from optional anonymous usage statistics.

This notice describes the current public sharing behavior. Statements about local chats and no automatic content collection do not cover content you deliberately publish. For deletion requests or abuse reports, contact the website email below and include the public share link.
