# DeskFox 界面交互测试工具包(uiprobe)

> [fork-only] 长期复用,不是一次性脚本。[feat: ui-probe-toolkit] 2026-08-13
>
> **立此工具包的原因**:2026-08-12/13 连续两天出现「修了又复发」「验证报绿但其实没验到」。
> 复盘结论是**缺工具**而非缺判断力 —— 同一类失误反复出现,每次都靠临时脚本对付,下次照样踩。
> user 明确要求把它做成工具、进工具包、持续复用。

## 一、已建能力(每条都对应一次真实翻车)

| 能力 | API | 对应的翻车 |
|---|---|---|
| **窗口/屏幕/视口几何** | `window_geometry()` | 窗口跑到副屏(x=-1694),点击坐标全部落空,却当成「功能正常」 |
| **视口硬断言** | `assert_in_viewport()` | 三连假绿:目标 y=1083 超出视口 900、x=-1623 在副屏、元素滚出可视区 |
| **真实输入** | `click/key/drag` | `element.click()` 是合成事件,触发不了 SolidJS handler → 误判「侧栏 toggle 失效」 |
| **元素定位(多策略+未命中自动截图)** | `find_element()` | 选择器两次不命中(`.cm-content` 不存在),差点断定「功能坏了」 |
| **遮挡检测** | `is_occluded()` | 分隔线「画了但被子元素覆盖」;查找框关闭按钮被右侧面板盖住 |
| **溢出检测** | `overflow_of()` | 聊天区恒定溢出 40px,压住右上角功能按钮 |
| **焦点探测** | `focus_state()` | 点击文件树后 `activeElement` 竟是 body —— 键盘作用域 bug 的根因 |
| **可靠指标读取** | `css_var()` | `innerText.includes()` 被同名文案污染,判定结论错 |
| **像素级验收** | `zoom_shot()` / `sample_column()` | 读 computed style 说「1px solid」,放大 8 倍才发现那片是纯白 |

**自检**:`python3 uiprobe_selftest.py` —— 14 项,含**反向验证**(伪造越界坐标必须被拦下)。
工具本身没验过就是新的假绿源,故自检与工具同时交付。

## 二、三条硬规矩(工具替你守住)

1. **真实输入**,不用合成事件。
2. **可靠指标**,不用文案判定 —— 读驱动行为的变量/几何本身。
3. **视觉改动像素级验收** —— 样式挂上了 ≠ 用户看得见。

## 三、坐标系(这次翻车的总根源)

- **屏幕坐标**:多屏时可为负。`screencapture` / AppleScript 用这套。
- **视口坐标**:CDP `Input.dispatch*` 与 `getBoundingClientRect()` 用这套。

两者**绝不能混用**。`window_geometry()` 同时给出两套并标注所在屏幕;
窗口在副屏时会显式告警「screencapture 截主屏会得到空白,截图一律用 `UI.shot()/zoom_shot()`」。

## 四、还需要补的能力(按价值排序,尚未实现)

沿同一思路往下看,以下几项是当前测试工作里仍在靠人肉补的部分:

1. **双版本对照跑**(优先级最高)
   同一探针脚本分别跑基准版与当前版,自动 diff 结果。
   现在每次比对都要手工启停两个包、肉眼比对输出 —— 这正是「参照原来的 fork 逐一比对」的机械化。
   卡点:同 appId 有单例锁不能并存,需支持交替运行 + 结果落盘后比对。

2. **操作序列录制/回放**
   把一次手工路径(点开文件 → 点别处 → 按 Enter)录成可重放脚本。
   本次三个 bug 的复现路径都是手工描述的,回归时靠人复述容易漏步。

3. **前后状态结构化快照 + diff**
   操作前后各存一份(面板开合 / 焦点 / 关键几何 / 溢出量),自动指出变了什么。
   现在是零散地读几个字段,容易漏掉「修了 A 坏了 B」——
   自动收起那次就是新功能劫持了侧栏 toggle,而我只盯着新功能自己的指标。

4. **面板组合矩阵遍历**
   文件树/审查/预览/终端/侧栏 的开关组合自动遍历,每种组合验一遍不遮挡、不溢出。
   `flex-row-reverse` 复发正是因为只测了「文件树+聊天」,没测「审查+文件树同开」。

5. **native 层探测封装**
   原生菜单树、托盘菜单、Dock 行为的 AppleScript 已经写过多次,应沉淀成 API。
   e2e 在这层**原理上无能为力**(web 端整棵桌面子树不渲染)。

6. **可访问性快照**
   全量 `aria-label` / role 清单落盘,与基准 diff —— 能机械发现「按钮没了/改名了」。
   本次靠它发现了 10 个此前遗漏的交互入口(通知面板 alt+T、复制消息、上下文用量等)。

## 五、与既有 smoke 系统的关系

`smoke.py` 是**广度**扫描(把每个供应商/面板/设置页点一遍,抓崩溃);
`uiprobe` 是**深度**工具(定位到像素、坐标、焦点、遮挡)。
前者回答「有没有炸」,后者回答「为什么不对、到底哪一层不对」。两者互补,不重叠。
